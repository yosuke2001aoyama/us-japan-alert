# JPUS Alert — 米国・日米関係速報

日米の主要報道、政府・議会の一次情報、要人発信を横断し、官僚・報道関係者が「まだ大きく報じられていない重要シグナル」を先に確認するための公開モニタリングデスクです。

## できること

- White House、国務省、国防総省、Congress.gov、首相官邸・外務省・防衛省などの一次情報を選別取得
- Truth Socialの公開APIから @realDonaldTrump の発信を取得
- Google News RSSを使い、日米の主要紙・通信・テレビ・政治メディアを横断
- 首脳・閣僚、同盟・安保、通商・制裁、議会・重要人事を優先し、領事・在留・定例広報を除外
- 訪米や首脳会談の調整・検討・観測段階の報道も監視
- 画面は110秒ごと（2分以内）に自動更新。時系列順／重要度順、対象期間、分野、一次情報で絞り込み
- 英語記事は「仮訳」を押したときだけ、見出し・要旨の機械翻訳を表示
- 「要確認」「報道前候補」「未確認」の確認キュー、原爆・戦争認識や米議員発言などの重点ウォッチ
- 総理訪米などの調整報道、政府筋・関係者情報、本人が記者団やインタビューで先に明かした重要発言も「報道・観測」として継続監視
- 原文・公表時刻・表示理由・検証区分を同じ行に集約し、端末ごとに確認済み状態を保存
- 同一URLの重複排除、検索、原文ハイパーリンク、CSV出力
- 監視ワーカーが60秒ごとに再取得し、重要新着を記事単位・媒体単位で直ちにメール通知
- 公開画面から二段階確認（double opt-in）で速報メールを登録し、各メールから解除可能
- 同じ記事の再通知は抑止し、同一事象でも別媒体の記事は別通知として維持
- 一つの取得元が落ちても、他の監視を継続

## ローカル起動

```bash
npm ci
npm run dev
```

## 通知

監視ワーカーは起動後110分間、60秒ごとに公開フィードを確認します。GitHubの定期実行開始が遅れても、稼働中のワーカーが監視を継続します。重要新着は検知した走査で1記事ずつ配信し、同じ記事には受信者ごとの冪等キーを付けて二重送信を防ぎます。

GitHub Actions secrets に次を登録します。

- `RESEND_API_KEY`
- `ALERT_TO_EMAIL`
- `ALERT_FROM_EMAIL`（Resendで認証済みドメインの送信元）
- `ALERT_SIGNING_SECRET`（32文字以上のランダム値。Vercelと同一値）

Actions variable `PUBLIC_DASHBOARD_URL` に公開URLを登録します。メール用の秘密情報が未登録でも、収集・公開画面・GitHub通知は動きます。
原爆・被爆・日本降伏などに関する議員・政府関係者の一次発信は、通常の通知しきい値より低い重要度82から早期通知できます。必要に応じて Actions variable `ALERT_EARLY_SIGNAL_PRIORITY` で変更してください。

公開登録を有効にするため、VercelのProduction環境にも次を登録します。

- `RESEND_API_KEY`
- `ALERT_FROM_EMAIL`
- `ALERT_SIGNING_SECRET`
- `PUBLIC_DASHBOARD_URL=https://us-japan-alert.vercel.app`

登録前に30分期限の確認メールを送り、メールボックスの所有確認後に専用セグメントへ追加します。確認・解除URLにはメールアドレスを含めず、AES-256-GCMで暗号化した期限付きトークンだけを使用します。APIは同一オリジン検査、サイズ制限、ハニーポット、レート制限、汎用応答を使用し、購読者一覧を公開しません。

## 運用上の注意

「全メディア」の完全取得を保証するものではありません。公開RSS、検索RSS、公開APIで取得可能な範囲を広く監視し、ペイウォール記事は見出しと原文リンクを扱います。スクレイピング回避、出典明示、原文確認を前提としています。各提供元の仕様変更や利用規約変更に応じて取得経路を更新してください。
